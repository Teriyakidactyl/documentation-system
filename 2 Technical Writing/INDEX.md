# Technical Writing

This location collects the repository-agnostic authoring procedure for
technical documented information. Document Control governs the resulting
artifact; this location governs how the document is conceived and written.

  - `Read in full and follow when` *authoring a technical document* `to` **commit its description, controlled placement, quadrant, outline, and writing style before drafting prose that satisfies them**.
