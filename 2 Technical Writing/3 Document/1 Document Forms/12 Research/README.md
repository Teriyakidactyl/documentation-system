# Research

Research uses two coupled document roles. A Research Prompt preserves the
rerunnable investigation specification. A Research Report preserves the output
of one execution of that prompt.

The prompt and reports belong to one investigation folder. Reports identify the
prompt by UID so repeated runs can be compared without treating the report as
current governing authority.
