# Document Forms

This location collects canonical Document Forms for recurring document roles.
A Document Form is the reusable whole-document structural type; control here
makes that form the adopted standard for its role.

Ordinals 1–9 are reserved for Document Forms guidance. Reusable forms begin at
ordinal 10 so guidance can grow without interleaving with the forms it governs.
