# Document Forms

This location collects canonical Document Form packages for recurring document
roles. A Form is represented by a numbered directory whose `README.md` owns
the Form identity. Every package separates its canonical Reference from its
assembly HowTo; a Tutorial is added when recurring judgment needs discriminating
examples.

Ordinals 1–9 are reserved for Document Forms guidance. Form packages begin at
ordinal 10.
