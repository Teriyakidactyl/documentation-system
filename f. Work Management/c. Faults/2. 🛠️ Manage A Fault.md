# 🛠️ Manage A Fault

## 1. Capture the observed failure

Create or identify a Fault Work Object under `.project/Intake/Faults/`.
Record the observation, expected behavior, affected state, and smallest useful
reconstruction evidence.

Do not write a causal conclusion into the observation merely because one cause
looks likely.

## 2. Link retained evidence

When an existing Fault Record, Validation record, test failure, log, commit, or
other evidence already reconstructs the event, link it rather than copying its
full contents into the Fault Work Object.

Legacy `.fault/` records can remain in place as evidence.

## 3. Decide whether investigation is independent work

Keep analysis inside the Fault when it is bounded and naturally co-occurs with
the fault record.

Create an Investigation under `.project/Planning/Investigations/` when the
causal question has its own scope, dependencies, experiment sequence, or
handoff lifecycle.

Relate the Investigation to the Fault with `derives-from` or `concerns`.

## 4. Create remediation work

Create one or more Tasks for independently executable remediation outcomes.
Use `remediates` to connect each Task to the Fault.

Do not overload the Fault itself as an execution checklist when remediation has
independent state.

## 5. Establish recurrence control

Identify the mechanism that should prevent or detect recurrence. Put its current
rule in the artifact that owns that mechanism.

Link the Fault to that control as evidence of the historical reason for it.

## 6. Verify the fault acceptance boundary

Confirm the required repair, investigation, validation, and recurrence-control
conditions established for this Fault.

Residual desirable work that is not required to close the Fault becomes
separate Work Objects rather than keeping the Fault indefinitely active.

## 7. Close the Fault

Apply Close Work with the appropriate disposition and retention.

A cold Fault can move beneath `.project/Archive/`. Preserve its UID, Work ID,
causal links, remediation links, and surviving evidence references.
