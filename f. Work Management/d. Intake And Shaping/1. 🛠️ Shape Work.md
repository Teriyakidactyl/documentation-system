# 🛠️ Shape Work

## 1. Preserve the incoming signal

Capture enough of the signal to prevent loss of meaning. Record its source or
subject when that fact affects later interpretation.

Do not rewrite an Idea as an Issue or Feedback as a Task merely to fit a
preferred template.

## 2. Classify the current Work Object

Select the narrowest kind whose meaning is already supported:

- Idea for a possibility;
- Feedback for an observation, request, reaction, or critique;
- Issue for a recognized condition requiring attention;
- Fault for an observed failure;
- Investigation when reducing uncertainty is itself the work;
- Task when one executable outcome is sufficiently bounded; or
- Plan when several nodes need coordination.

Keep ambiguity explicit when the available evidence does not determine the kind
yet.

## 3. Detect an existing object

Search active and relevant archived Work IDs and titles for the same work.

When another object already owns it, relate and close the duplicate rather than
creating parallel active truth.

## 4. Determine the next disposition

Choose one:

- retain as captured input;
- promote to an executable Task;
- open an Investigation;
- attach to an existing Plan;
- create a Plan when coordination is required;
- defer until a named condition;
- reject with a reason; or
- merge/convert into another Work Object.

One signal can produce several work objects when their acceptance conditions or
lifecycles differ.

## 5. Create explicit relations

Relate the resulting work back to its source with edges such as
`derives-from`, `concerns`, `remediates`, or `coordinates`.

Do not rely on matching folder names or prose proximity to preserve provenance.

## 6. Establish actionability

For a promoted Task, apply Record A Task and set `ready` only when starting
conditions are satisfied.

For coordinated work, follow Plan Work. For Fault-specific evidence and causal
handling, follow Manage A Fault.

## 7. Close or retain the intake object

When the input has completed its intake job, close it with `converted`,
`duplicate`, `rejected`, or another accurate disposition, or keep it
captured when it still has an active intake purpose.

Do not delete the only record explaining why resulting work exists.
