# Planning Reference

This location retains planning-support source material used to broaden,
interrogate, or compile plans when ordinary decomposition is insufficient.

The material is reference input, not current Work Management authority. Apply
only the methods that address a concrete planning weakness, and keep the Plan's
actual Nodes, Relations, Gates, and acceptance conditions in the Plan.
