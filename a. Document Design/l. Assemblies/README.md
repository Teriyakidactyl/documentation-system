# Assemblies

Within Document Design, Assemblies collects reusable representations that are
selected and composed rather than designed anew for each document instance.

A **Document Form** governs whole-document source arrangement for a recurring
document role. A **Document Element** governs one reusable heading-bounded
structure inside a document. The consuming document owns its subject-specific
content in either case.

Forms and Elements are both Assembly types. The distinction is their structural
scope, not whether one is reusable and the other is merely a part.
