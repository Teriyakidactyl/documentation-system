# Records

Records are Document Forms whose instances primarily preserve information rather
than executable work state.

A Record can motivate, concern, derive, evidence, or otherwise relate to work
without thereby becoming a Task or Plan. Each child Form owns its specialized
contract; this grouping owns only the shared routing boundary between retained
information and executable work.

Research remains a grouping of separate Research Prompt and Research Report
Forms because their instance contracts and assembly procedures differ.
