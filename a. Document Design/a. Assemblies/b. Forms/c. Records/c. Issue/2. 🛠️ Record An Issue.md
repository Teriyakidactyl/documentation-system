# 🛠️ Record An Issue

## 1. State the condition

Describe one recognized condition that requires attention or an explicit
disposition. Do not encode the proposed solution as the condition.

## 2. Preserve evidence

Record the observations, references, or checks that establish the condition.

## 3. State material impact

Identify what is affected and why attention is warranted.

## 4. Relate resulting work

When remediation, investigation, or planning is required, create or select the
appropriate Work Management object and relate it to the Issue.

## 5. Bind and control the Form

Bind the record to this Form package when Form provenance applies and let
Organizing mint or preserve controlled identity.
