# 📐 Architecture

This store contains current Architecture Documents for implementations rooted in
Tooling.

Architecture Documents are current design authority. Decision records,
research, fault evidence, and Git history may explain or evidence the design but
do not replace it. An implementation may also carry a direct controlled
`architecture` link to its governing document.

### 📖 Organizing Architecture

`Consult when` *the Organizing tool, an organization scheme, a peer
representation capability, a validation rule, a projection, or a structural
refactor is being introduced or materially changed* `to` **place
responsibility with the owning capability while preserving one normalized
corpus and one deterministic organization workflow**.
