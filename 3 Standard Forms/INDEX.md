# Standard Forms

This location collects default opinions and reusable forms for recurring
repository documents such as `README.md` and `INDEX.md`.

Ordinals 1–9 are reserved for Standard Forms guidance. Reusable forms begin at
ordinal 10 so guidance can grow without interleaving with the forms it governs.
