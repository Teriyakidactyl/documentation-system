# Architectures

This location collects formal architectures owned by Error Management. Each
architecture fixes a reusable arrangement of Error Management concepts for a
recurring constraint.

The architecture Reference inside each package is current authority. Research,
decision provenance, and other supporting material may accumulate beside it
without replacing that authority.
