# Project Records

This folder is a collector: its children share the `.project` sideband's
controlled, address-opaque retrieval boundary, but they do not share semantic
ownership.

- `Drafts/` retains working drafts intentionally kept with repository project
  state.
- `Faults/` retains Fault Record instances.
- `Research/` retains research prompts and reports, grouped by investigation.

Containment here does not make these artifacts Work Objects. Their Forms,
authority posture, and lifecycle semantics remain owned by the guidance for
their individual record kinds. Read only the record category required by the
current task.
