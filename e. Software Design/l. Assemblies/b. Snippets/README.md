# Snippets

Snippets are the smaller-fragment Assembly type for Software Design.

Use this location for reusable source-level representations whose selection does
not itself adopt a whole Software Specification Blueprint. No canonical
Snippets are currently defined; this location establishes the routing boundary
without inventing examples merely to populate it.
