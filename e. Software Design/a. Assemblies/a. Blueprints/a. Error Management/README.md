# Error Management Blueprints

This location collects Software Specification Blueprints owned by Error Management. Each
Blueprint fixes a reusable arrangement of Error Management concepts for a
recurring constraint.

Each package specifies one reusable Blueprint. Its Reference is current reusable design authority; a live implementation adopts it only through that implementation's Software Architecture Specification. Research,
decision provenance, and other supporting material may accumulate beside it
without replacing that authority.
