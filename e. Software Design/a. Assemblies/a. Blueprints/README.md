# Blueprints

Software Specification Blueprints are whole-design Assemblies. A Blueprint
fixes a durable reusable arrangement for a recurring selecting condition while
remaining subordinate to the Software Architecture Specification of any live
implementation that adopts it.

Blueprints remain grouped by the Software Design concern that owns the
selecting condition and reusable design knowledge.
